Project: Alpine Ascents
Type: Responsive single-page mountaineering information website
Frontend: React, HTML5, CSS3, JavaScript and Bootstrap
Data file: src/data.json
Images: public/images/ (separate folder with mountain photographs)

How to run:
1. Install Node.js.
2. Open the project folder in Visual Studio Code.
3. Open the terminal in the project folder.
4. Run: npm install
5. Run: npm run dev
6. Open the local address shown in the terminal.

Project notes:
- The visitor counter is saved in the visitor's browser using Local Storage.
- Location is requested only when the visitor presses the location button.
- The map and video resources need an internet connection.
- This is an informational website and does not include bookings, accounts or a backend database.
