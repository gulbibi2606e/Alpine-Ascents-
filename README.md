# Alpine Ascents – Mountaineering Information Website

A simple React single-page website made as a student semester project. It shares beginner-friendly information about mountaineering, mountain safety, climbing styles and mountain locations.

## Technologies used
- React – to build the website interface
- JavaScript – for buttons, navigation and small functions
- HTML5 and CSS3 – for page structure and design
- Bootstrap 5 – for responsive layout support
- JSON – to keep records, club details and update text in one data file
- Vite – to run the project during development

## Project folders
- `src/App.jsx` – main website code
- `src/main.jsx` – starts the React application
- `src/style.css` – website colours, layout and responsive styling
- `src/data.json` – sample website information
- `public/images/` – separate folder containing the mountain photographs used on the website

## Run the project
1. Install Node.js on your computer.
2. Extract the project ZIP file.
3. Open the `Alpine_Ascents_Fresh` folder in Visual Studio Code.
4. Open the terminal in that folder.
5. Run `npm install`.
6. Run `npm run dev`.
7. Open the local address shown in the terminal (usually `http://localhost:5173`).

## Important notes
- The visitor counter is saved in the current browser only. It is not a total count for all website visitors.
- Location is optional. The browser asks permission only after the visitor presses the location button.
- The map and external video links need an internet connection.
- The website is an information project. It does not have a booking system, user accounts or a backend database.
